# Photos Vault

A simple web app for storing, organising and finding your photos.

## Features

- Upload photos and videos
- Browse your library by date
- Create albums
- Favourite photos
- Select multiple photos to share, favourite or delete
- Send photos to the trash
- Sign up, log in and log out

## Tech stack

- Next.js
- PostgreSQL
- Cloudinary for photo files
- Better Auth for sign-in

## Getting started

### Prerequisites

- Node.js 18 or later
- PostgreSQL
- A storage bucket for uploads

```bash
git clone https://github.com/NhloniphoStack/photos-vault.git
